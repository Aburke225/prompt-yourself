# Prompt Yourself

**Learn any topic. Prep for any interview. All it takes is a free AI chat — and knowing what to say to it.**

A free guide site, live at https://aburke225.github.io/prompt-yourself/

No courses, no accounts, no hosted coach. Two guides:

- **Learn any topic with AI** — how to use a free AI chat (plus free sites) to actually learn something, not just get answers.
- **Build your own AI interview coach** — how to write a coach prompt for *your* interview, whatever the field, and run it in a free AI chat.

Plain HTML/CSS, no build step. By [Andrew Burke](https://github.com/Aburke225).
